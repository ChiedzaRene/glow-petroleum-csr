Section 2

Which option should I use?

Recommended

A · Single-file paste

Paste one file into one Custom HTML block.

  • Looks exactly like the mockups
  • Takes about 5 minutes
  • Works on any theme
  • Text and photos are changed in code
Easiest to maintain

B · WordPress blocks

Paste once into the Code editor, then edit everything visually.

  • Click to change text and photos
  • Add slides through a Gallery block
  • Takes about 15 minutes
  • Some themes change the look slightly
If the site uses Elementor

C · Elementor

Rebuild the layout with Elementor widgets, or paste file A into one HTML widget.

  • Drag-and-drop
  • Some widgets need Elementor Pro
  • Takes 1–2 hours to rebuild
How to tell which editor the site usesGo to Pages → All Pages and hover over the CSR page. If you see Edit with Elementor, the site uses Elementor (use Option C, or paste file A into an Elementor HTML widget). Otherwise it uses the standard WordPress Block Editor (use Option A or B).
Only one option per pageChoose one option. Don't paste both into the same page, or the page will show twice.
Section 3

Before you start

  1. Log in as an AdministratorWordPress only lets Administrator accounts save code that contains <script>, which the slideshow needs. To check, go to Users → Profile and look at Role. On a WordPress Multisite network, only a Super Admin can do this.
  2. Back up the current pageOpen the existing CSR page in the editor, then use ⋮ (top right) → Copy all blocks and paste the result into a text file. You can also rely on Revisions in the page sidebar, which lets you restore the old version at any time.
  3. Prepare the photos
    WhereHow manyBest size
    Header slideshow5 (you can add or remove some)1920 × 1080, landscape
    Golf / Netball / Tug of War cards1 each1200 × 900
    MSAA21200 × 900
    Community gallery31200 × 900
    Keep each photo under about 400 KB so the page loads fast. You can shrink them for free at squoosh.app or tinypng.com. Pick bright, action-filled photos with people in them.
  4. Use a full-width page templateThe design is made to run edge-to-edge. In the page editor, open the Page settings sidebar. Under Template (or in the theme's own panel), choose Full Width, No Sidebar or Blank / Canvas. The exact names depend on the theme.
  5. Optional: practise on a draftCreate a new page with Pages → Add New, build everything there, and preview it. Once it looks right, copy the content into the real CSR page.
Section 4

Option A – Single-file paste (recommended)

Use the file single-file/glow-csr-wordpress-paste.html.

  1. Open the file in a plain text editorRight-click the file → Open with → Notepad on Windows or TextEdit on Mac. Don't double-click it, because that opens it in a browser. A free code editor such as VS Code or Notepad++ makes finding things easier.
  2. Copy everythingPress Ctrl + A, then Ctrl + C (Mac: ⌘ + A, ⌘ + C).
  3. Open the CSR page in WordPressGo to Pages → All Pages, hover over Our Corporate Social Responsibility and click Edit.
  4. Remove the old contentClick into the content area, press Ctrl + A twice to select every block, then press Delete. (Make sure you did the backup in Section 3 first.)
  5. Add a Custom HTML blockClick the blue + (Block Inserter) at the top left, search for Custom HTML and click it.
  6. Paste the codeClick inside the Custom HTML block and press Ctrl + V. The block fills with code. That's expected: the editor shows code, and the published page shows the design.
  7. Preview itClick Preview in the block toolbar to check it there, or use Preview → Preview in new tab at the top right.
  8. Set the full-width templateIn the right sidebar, under Page → Template, choose Full Width or No Sidebar.
  9. SaveClick Update, or Publish for a new page. Then open the live page and refresh it.
Page title showing twice?The page has its own big header, so you can hide the theme's page title if it appears above it. Many themes have a Disable Title checkbox in the page sidebar.
Don't press "Convert to blocks"If WordPress offers to convert the Custom HTML into blocks, ignore it. Converting breaks the design.
Section 5

Replacing the placeholder photos

The page ships with drawn placeholder pictures that are stored inside the file as very long lines of text starting with data:image/svg+xml;base64,. You replace each one with the web address (URL) of a real photo.

Step 1 – Upload the photos and copy their URLs

  1. Go to Media → Add New Media File and drag in your photos.
  2. Click a photo. In the panel on the right, click Copy URL to clipboard. It will look like https://glowpetroleum.com/wp-content/uploads/2026/10/golf-day.jpg.
  3. Fill in the Alternative Text box too (for example, "Glow Petroleum netball team celebrating"). It helps Google and visually impaired visitors.

Step 2 – Swap the URL into the code

Each picture has a label called alt="…" right after its long src="…". Use Ctrl + F to find the label, then replace the src just before it.

BEFORE (shortened – the real line is very long):
<img src="data:image/svg+xml;base64,PHN2ZyB4bWxucz0i....Pg==" alt="Golf">

AFTER:
<img src="https://glowpetroleum.com/wp-content/uploads/2026/10/golf-day.jpg" alt="Golf">
The easiest way to select the long textIn VS Code or Notepad++, double-click inside the long text. Most editors select the whole base64 block in one go. You can also click right after src=", then Shift + click just before the closing ".

Section 6

Editing text, links, slides and colours

Changing text

Find the words with Ctrl + F and type over them. Only change the words between the tags, never the < > parts.

<h3>Netball</h3>
<p>The Glow Petroleum netball team competes in the Rainbow Netball League…</p>
Special charactersWrite &amp; instead of a plain &, for example Sports &amp; Culture. Other characters such as apostrophes and dashes are fine as they are.

Changing button links

Links live in href="…". The "See golf highlights", "Meet the team", "View the action" and "Learn more about MSAA" buttons currently point to #, which goes nowhere. Replace each # with a real page or news-article URL. "Get in touch" points to /index.php/contact-us/. Change it if your contact page has a different address.

<a class="gc-more" href="#">Meet the team →</a>
<a class="gc-more" href="https://glowpetroleum.com/index.php/netball/">Meet the team →</a>

Adding or removing a header slide

Each slide is one small block. To add a slide, copy a whole block and paste it below the last one, then change the picture, the caption and the alt text. To remove a slide, delete its whole block. The dots update by themselves.

<div class="gc-slide" data-caption="<b>Community</b> · Giving back">
  <img src="https://…/your-photo.jpg" alt="Describe the photo">
</div>

Changing the colours

All the colours are set in one place near the top of the <style> section. Change a hex code and the whole page follows.

SettingCurrentUsed for

--glow-yellow#ffc23dSecond gradient colour, slideshow progress bar

Slideshow speed: search for DELAY = 6000 and change the number (in milliseconds, so 6000 = 6 seconds). Then search for gcBar 6s and change it to match (for example gcBar 8s).

Section 7

Option B – WordPress blocks (visual editing)

Use the file wordpress-version/option-2-gutenberg-blocks.txt. Once it's in, your team can change photos and text by clicking, with no code.

  1. Copy the fileOpen it in Notepad, press Ctrl + A and then Ctrl + C.
  2. Switch the page to the Code editorEdit the CSR page, click ⋮ (Options, top right) → Code editor. The shortcut is Ctrl + Shift + Alt + M.
  3. PasteDelete anything already in the big text box, then press Ctrl + V.
  4. Go back to the visual editorClick Exit code editor. You now see real blocks: a gallery, headings, columns, images and buttons.
  5. Fix any warningsIf a block shows "This block contains unexpected or invalid content", click Attempt recovery. Small differences between WordPress versions cause this, and it's safe.
  6. Set Full Width, preview and UpdateSame as Option A, steps 8–9.

Keep the "Additional CSS class(es)"The design relies on class names stored in each block under Block settings → Advanced → Additional CSS class(es), such as glow-hero, glow-card glow-card--golf and glow-section glow-sport. Don't clear these. When you duplicate a block, the classes come with it.
Don't delete the first and last blocksThe first block (Custom HTML) holds the styles and the last one holds the slideshow script. Without them, the page looks plain and the slideshow doesn't move.

Optional: move the styles into the theme

Paste glow-wp-blocks.css into Appearance → Customize → Additional CSS, and add glow-wp-blocks.js as a Site Wide Footer JavaScript snippet with the free WPCode plugin. Then delete the first and last Custom HTML blocks.

Section 8

Option C – Building it in Elementor

Quick route: paste file A into Elementor

  1. Click Edit with Elementor on the CSR page.
  2. Click the ⚙ page settings (bottom left) and set Page Layout to Elementor Full Width or Elementor Canvas.
  3. Drag an HTML widget onto the page and paste all of glow-csr-wordpress-paste.html into it.
  4. Click Update. Photos are swapped in the same way as Section 5.

Full route: rebuild it with Elementor widgets

Set up the brand first in ☰ → Site Settings → Global Colors: Primary #f26b1d, Secondary #ffc23d, Text #1b2236, Accent #0f1d3a. In Global Fonts, use Montserrat 800 for headings and Poppins for body text. Then build each section:

Section 9

Troubleshooting

ProblemFix
The slideshow doesn't move and the sections stay invisible or plainThe script was removed when you saved. Log in as an Administrator and paste again (see Section 3). Some security plugins (Wordfence, iThemes) also block scripts in posts. Allow it, or use the WPCode method from Section 7.
Changes don't show on the live siteClear the cache. Caching plugins such as LiteSpeed, WP Rocket, W3 Total Cache and Autoptimize each have a Purge / Clear cache button in the top admin bar. Then refresh your browser with Ctrl + F5.
The page is squashed with a sidebar, or there are white gaps at the sidesSet the page Template to Full Width or No Sidebar (Section 3, step 4).
The page title shows twiceTick Disable title in the page sidebar, or hide it in the theme's page options.
The pillar menu hides behind the site's top menu when scrollingSearch the code for position: sticky; top: 0; and change 0 to the height of your site header, for example top: 80px;.
A photo shows as a broken imageThe URL is wrong. Copy it again from Media and make sure it ends in .jpg, .png or .webp and sits inside the quotes.
The layout suddenly looks broken after editingA tag was probably deleted by accident. Use Revisions in the page sidebar to go back, or paste a fresh copy of the file and redo the changes.
"Invalid content" warning (Option B)Click Attempt recovery. If that doesn't work, use ⋮ → Resolve → Convert to HTML for that one block.
The fonts look differentSome privacy or speed plugins block Google Fonts. The page then uses a similar system font, which is fine. To force the fonts, allow fonts.googleapis.com in the plugin.
Arrows or buttons look oddThe theme's button styles are overriding the page. Use Option A, whose styles are protected inside .glow-csr, or ask a developer to raise the CSS priority.
Section 10

Checklist before publishing

  • All 13 placeholder pictures are replaced with real photos. Search for data:image: there should be no results.
  • Every photo has a meaningful alt description.
  • The MSAA text has the full name of the programme and accurate details.
  • The Golf (Liberty Gumisa) and Netball (Rainbow Netball League) details are still current.
  • The four stat boxes show correct figures. Consider real numbers such as learners supported or events held.
  • Every href="#" button is changed to a real link or removed.
  • "Get in touch" opens the correct Contact page.
  • The page template is Full Width / No Sidebar.
  • The slideshow fades and the dots and arrows work.
  • The page has been checked on a phone: swipe the slideshow and scroll all sections.
  • The cache has been cleared and the live page checked in a private browser window.
  • The SEO plugin (Yoast / Rank Math) title and description are updated for the page.
Need changes later?Every version of the code is saved in the GitHub repository ChiedzaRene/glow-petroleum-csr. If something goes wrong, download the file again and start fresh.

How it looks on a phone

On phones, the cards stack, the pillar menu scrolls sideways, and visitors can swipe through the slideshow. Check this before publishing, because most visitors arrive on a phone.
